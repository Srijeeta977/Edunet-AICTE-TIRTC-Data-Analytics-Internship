# Healthcare Analytics for Doctor Visits

### Edunet Foundation – AICTE/TIRTC Data Analytics Internship

A Data Analytics project focused on exploring patterns in doctor visits using demographic and health-related attributes. The project applies Exploratory Data Analysis (EDA), statistical summaries and data visualization to understand how doctor visits vary with factors such as age, gender and illness score.

---

## 📌 Project Overview

Healthcare data can provide useful insights into patient characteristics and patterns of healthcare utilization.

This project, **Healthcare Analytics for Doctor Visits**, analyzes a healthcare dataset to explore the distribution of doctor visits and investigate relationships between doctor visits and selected demographic and health-related variables.

The analysis focuses on understanding:

- Gender distribution
- Age distribution
- Distribution of doctor visits
- Average doctor visits by gender
- Relationship between illness score and average doctor visits
- Distribution of visits across gender
- Relationship between age, doctor visits and gender

The project uses Python-based data analysis and visualization techniques to transform the raw dataset into understandable analytical insights.

---

## 🎯 Objectives

The main objectives of this project are:

- Explore and understand the healthcare dataset.
- Examine the distribution of important variables.
- Analyze the distribution of gender and age.
- Study the distribution of recorded doctor visits.
- Compare average doctor visits across genders.
- Investigate the relationship between illness score and doctor visits.
- Analyze the distribution of visits by gender.
- Examine the relationship between age and doctor visits while considering gender.
- Present the findings using appropriate visualizations.

---

## 📊 Analysis Performed

### 1. Dataset Exploration

The notebook begins with basic dataset exploration, including:

- First and last records
- Dataset dimensions
- Dataset information
- Descriptive statistics
- Missing-value checking

### 2. Univariate Analysis

The following individual variables are analyzed:

- **Gender Distribution**
- **Age Distribution**
- **Doctor Visits Distribution**

### 3. Gender and Doctor Visits

The project calculates:

- Number of records by gender
- Mean doctor visits by gender
- Median doctor visits by gender

A bar chart is used to compare average doctor visits between genders.

### 4. Illness Score and Doctor Visits

The analysis groups records by illness score and calculates average doctor visits.

A visualization is used to examine the relationship between:

**Illness Score → Average Doctor Visits**

### 5. Multivariate Analysis

The project performs multivariate analysis using:

- Gender vs. Doctor Visits
- Age vs. Doctor Visits
- Gender as an additional variable in the age–visit relationship

Box plots and scatter plots are used to visualize these relationships.
